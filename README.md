# BRACKET — Красная смена

Изометрический браузерный шутер. Пройди через квартал к метро, найди тайники с оружием и переживи три волны мутантов. У фургона на рынке Глеб продаёт оружие за кредиты.

## Запуск

Скачай `Bracket-game.html` и открой его в браузере. Автономная версия содержит все нужные ресурсы. Для работы с исходниками открой `game/index.html`.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | WASD или стрелки |
| Огонь по курсору | Левая кнопка мыши |
| Огонь по ближайшей цели | Пробел |
| Рывок / ударная волна | Shift / E |
| Торговля у фургона | F |
| Выбор оружия | 1–9 |

## Разработка

Игровая логика находится в `game/game.js`, отрисовка и интерфейс — в `game/scene.js` и `game/index.html`. После изменений запусти из корня репозитория:

```sh
python scripts/build.py
node tests/playthrough.cjs
```

Первый скрипт пересобирает автономный HTML. Второй проверяет прохождение трёх волн до метро.
